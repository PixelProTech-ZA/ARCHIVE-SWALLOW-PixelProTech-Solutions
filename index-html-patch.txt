ARCHIVE SWALLOW — install-fix patch
====================================

1) In <head>, right after the <link rel="stylesheet" href="styles.css" /> line, add:

<link rel="manifest" href="manifest.json" />
<meta name="theme-color" content="#14181d" />
<link rel="apple-touch-icon" href="icon-192.png" />

2) Right before </body> (after <script src="app.js"></script>), add:

<script>
  if ('serviceWorker' in navigator) {
    window.addEventListener('load', () => {
      navigator.serviceWorker.register('service-worker.js').catch(console.error);
    });
  }
</script>

That's it. No other lines change.

UPLOAD LIST (flat, repo root, no subfolders):
- manifest.json          (new)
- service-worker.js      (new)
- icon-192.png           (new — was missing, generated from your existing icon-512.png)
- index.html             (edited — the two snippets above)

icon-64.png and icon-512.png you already have; leave them as-is.

After upload, hard-refresh the live page (Ctrl+Shift+R) — Chrome caches manifest
absence aggressively. If the install icon still doesn't appear in the address bar,
open DevTools → Application → Manifest to see what Chrome's validator flags.
